# Amber's SOC Analyst Portfolio

## Project Overview

A completed hands-on cybersecurity home lab designed to develop practical Security Operations Center (SOC) analyst skills through security monitoring, threat detection, incident investigation, and evidence collection.

## Lab Environment

- Oracle Linux Server 9.5
- Windows Subsystem for Linux (WSL2)
- Bash scripting
- Rsyslog
- Linux security and authentication logs

## Technical Investigations

- SSH authentication and simulated brute-force activity
- Suspicious login pattern analysis
- Network connections and DNS listener analysis
- Process and parent-child process investigation
- Security logging failure and remediation
- Privileged command and sudo activity analysis

## Project Accomplishments

- Completed six documented incident investigations.
- Collected and preserved ten evidence files.
- Developed a Bash-based SSH detection script.
- Investigated failed and successful authentication events.
- Identified and resolved a security logging configuration issue.
- Verified logging functionality following a system restart.
- Created structured technical documentation and incident reports.
